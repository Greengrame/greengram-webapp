# Security

Please report vulnerabilities privately, not in public issues: use
**Report a vulnerability** on this repository's Security tab (GitHub's
private vulnerability reporting). Tell us what is affected, how to
reproduce it and what an attacker gets. Remote code execution, account
takeover, auth bypass and anything that leaks other users' messages or keys
are the most important.

We answer within a week and fix what we can confirm as fast as we can. Once
a fix is out we credit you in the release notes, and request a CVE when it
warrants one, unless you'd rather not be named.

In scope: the Greengram changes on top of Telegram Web A. Out of scope: Telegram's own apps and services (report those to
Telegram), and bugs inherited unchanged from upstream (Telegram Web A; report those
upstream too).

Only the latest commit on the default branch gets fixes.
